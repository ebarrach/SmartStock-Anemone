# Module de visualisation Anémone

[Démarrage, JAR local et tests](../../README.md) ·
[Architecture et appels natifs](JLAMP24_TOOLS.md) · [Attribution](JLAMP24_NOTICE.md).

Ce module contient le frontend Scala.js/Laminar, les sources JVM du bridge,
les modèles stock/température, la politique thermique, les ressources et tous
les tests. `experiments/fixtures/legacy-web/` sert uniquement aux régressions des
contrôleurs historiques ; ces scripts ne sont pas chargés par l’interface active.
